# 満腹度システム

## 概要

フロア滞在時間を制限し、「稼ぎ vs 進行」のジレンマを生むタイマー機構。シレン系ローグライクの根幹要素。

## 基本仕様

| パラメータ | 値 |
|-----------|-----|
| 最大満腹度 | 100 |
| 初期満腹度 | 100 |
| 1ターンあたり減少量 | 0.1（内部的には整数管理: 1000が最大、1ターンで1減少）|
| 満腹度0時の効果 | 毎ターン HP が 1 減少 |

## 内部表現

表示上は 0〜100 だが、内部的には 0〜1000 の整数で管理し、小数の誤差を避ける。

```rust
struct Player {
    // ...
    fullness: i32,      // 0〜1000
    max_fullness: i32,  // 通常1000
}

// 表示時: fullness / 10 で整数表示
// 1ターンごと: fullness -= 1
// fullness <= 0 のとき: hp -= 1（毎ターン）
```

## 食料アイテム

| アイテム | 記号 | 満腹度回復量 | 備考 |
|---------|------|------------|------|
| 携帯食 | % | 50（内部500）| 基本食料 |
| 保存食 | % | 100（内部1000）| 最大まで回復 |

- 満腹度が最大を超える場合は最大値で止まる
- 最大満腹度が上がる要素は Phase 3 以降で検討

## 満腹度0時の挙動

1. 「お腹が空いて動けない...」のメッセージを表示（初回のみ）
2. 以降、毎ターン HP が 1 ずつ減少
3. 移動・攻撃等の行動は可能（行動不能にはしない）

## ゲームデザイン上の役割

- フロアに長時間留まってレベル上げする行為を制限する
- 携帯食の所持数管理が戦略的判断になる
- 「あと何ターン持つか」の計算がプレイヤーの思考を促す

## マスターデータ

満腹度関連のパラメータは `player.ron` および食料アイテムの `items/` で定義する。

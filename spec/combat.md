# 戦闘システム

## 概要

プレイヤーとモンスターが隣接した状態で攻撃を行い、ダメージを与え合うターン制の戦闘システム。

## 攻撃の発生条件

- **プレイヤー → モンスター**: モンスターのいるマスに向かって移動操作（8方向全て）を行うと、移動の代わりに攻撃が発生する（体当たり方式）
- **モンスター → プレイヤー**: モンスターがプレイヤーに隣接している場合、移動の代わりに攻撃を行う
- **斜め攻撃**: 斜め方向への移動入力でもモンスターがいれば攻撃が発生する

## プレイヤーの向き

- 移動・攻撃時に `direction` が更新される
- 向きを変えるだけの操作は Phase 2 以降で検討する

## ダメージ計算

### Phase 1（最小構成）

```
ダメージ = 攻撃側の攻撃力 - 防御側の防御力
最低ダメージ = 1（防御力が上回っても最低1ダメージ）
```

### Phase 2 以降（シレン風）

乱数幅を含む防御力逓減型に移行する:

```
基礎ダメージ = 攻撃力 × random(87.5%, 112.5%)
防御係数 = 35.0 / (35.0 + 防御力)
ダメージ = max(1, floor(基礎ダメージ × 防御係数))
```

ダメージ計算式はマスターデータで切り替え可能にする（[master-data.md](./master-data.md) 参照）。

### パラメータ（マスターデータで定義）

| エンティティ | HP | 攻撃力 | 防御力 |
|-------------|-----|--------|--------|
| プレイヤー（初期） | 30 | 8 | 5 |
| モンスター（1階基準） | 10 | 3 | 2 |

## 戦闘の流れ（1ターン）

1. プレイヤーがモンスターのいる方向に移動操作
2. 攻撃判定 → ダメージ計算 → モンスターのHP減少
3. モンスターのHP <= 0 → 撃破（マップから除去、経験値獲得）
4. モンスターのターン：隣接するモンスターがプレイヤーに攻撃
5. プレイヤーのHP <= 0 → ゲームオーバー

## 撃破時の処理

- モンスターをマップから除去
- 経験値を獲得（[growth.md](./growth.md) 参照）
- GameEvent::MonsterDefeated を発行
- メッセージログに表示

## 必要な実装変更

- Player構造体に `defense: i32`, `max_hp: i32` を追加
- Monster構造体に `defense: i32`, `name: String` を追加
- 移動処理にモンスターとの衝突時の攻撃分岐を追加
- モンスターの行動にプレイヤーへの攻撃を追加
- HP管理とゲームオーバー判定の追加
- 各処理で適切な GameEvent を返す

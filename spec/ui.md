# UI・フィードバック

## 概要

プレイヤーにゲーム状態を伝え、操作のフィードバックを提供する。UI層はRenderer traitで抽象化し、ゲームロジックと分離する（[architecture.md](./architecture.md) 参照）。

## 画面構成

```
+------------------------------------------------------+
| Floor 3/10                                           |  ← ヘッダー行
+------------------------------------------------------+
|                                                      |
|  aaaaa----bbbbb                                      |
|  a   a    b   b                                      |
|  a @Ma    b ! b                                      |
|  a   a----b   b                                      |
|  aaaaa    bbbbb                                      |
|                                                      |  ← マップ領域
+------------------------------------------------------+
| HP: 12/30  Lv: 2  Exp: 25/70  Floor: 3/10           |  ← ステータス行
| スライムに 5 ダメージを与えた                          |  ← メッセージ行1
| スライムを倒した！ 経験値 10 獲得                      |  ← メッセージ行2
+------------------------------------------------------+
```

## マップ描画

### Phase 1: 固定サイズ

マップサイズをターミナルに収まるサイズ（例: 80x24）に固定する。

### Phase 2 以降

プレイヤー中心のビューポートスクロールを検討する（シレン系の標準）。

## ステータス表示

画面下部に常時表示：

- **HP**: 現在HP / 最大HP
- **Lv**: 現在レベル
- **Exp**: 現在経験値 / 次のレベルに必要な経験値
- **Floor**: 現在階 / 最大階

## メッセージログ

画面最下部に直近2行分のメッセージを表示。GameEvent をメッセージに変換して表示する。

### メッセージ例

| GameEvent | メッセージ |
|-----------|-----------|
| PlayerAttacked | 「{target_name} に {damage} ダメージを与えた」 |
| MonsterDefeated | 「{name} を倒した！ 経験値 {exp} 獲得」 |
| MonsterAttacked | 「{name} の攻撃！ {damage} ダメージを受けた」 |
| ItemPickedUp | 「{name} を拾った」 |
| ItemUsed | 「{name} を使った {effect_desc}」 |
| LevelUp | 「レベルが {new_level} に上がった！」 |
| FloorAdvance | 「次の階へ進んだ」 |

※ メッセージテンプレートは将来的にマスターデータで管理可能にする。

プレイヤーのHP <= 0 で表示：

```

|                               |
|        GAME OVER              |
|                               |
|   到達フロア: 5/10            |
|   レベル: 3                   |
|   撃破数: 28                  |
|                               |
|   Press any key to exit...    |
|                               |
+-------------------------------+
```

## キー操作一覧

| キー | 操作 |
|------|------|
| h/j/k/l | 移動（左/下/上/右） |
| y/u/n/m | 斜め移動 |
| . | 足踏み（その場で待機、ターン消費） |
| i | インベントリ表示 |
| q | ゲーム終了 |

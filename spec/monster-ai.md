# モンスターAI

## 概要

モンスターがプレイヤーを検知し、追跡・攻撃を行うための行動ロジック。

## 行動パターン

### 基本ルール

モンスターは毎ターン以下の優先順で行動を選択する：

1. **攻撃**: プレイヤーに隣接している（8方向） → 攻撃
2. **追跡**: プレイヤーが視界内にいる → プレイヤーに近づく
3. **徘徊**: それ以外 → ランダム移動

### 行動順序

- 配列の先頭から順に処理する
- 先に行動したモンスターの移動結果は、後のモンスターの行動に反映される

### 視界（検知範囲）

- **同じ部屋にいる場合**: 常に検知（マップの `room_id` で判定）
- **通路にいる場合**: マンハッタン距離で5マス以内なら検知

※ 「同じ部屋判定」にはマップのセル表現を `room_id` 付きの構造体にする必要がある（[architecture.md](./architecture.md) 参照）。

### 追跡移動

プレイヤーとのマンハッタン距離が縮まる方向に1マス移動する。

```
dx = sign(player.x - monster.x)
dy = sign(player.y - monster.y)

候補: (dx, dy), (dx, 0), (0, dy) の順に試行
すべて移動不可の場合はランダム移動にフォールバック
```

## Phase 2 以降の拡張

- モンスター種別ごとの行動パターン（マスターデータの `ai_type` で定義）
  - Standard: 基本AI（追跡＋隣接攻撃）
  - Stationary: 近づかれるまで動かない
  - Ranged: 遠距離攻撃
  - 特殊行動（催眠術、変化、ブレス攻撃等）
- 逃走行動（HP低下時）
- 群れ行動
- 倍速・鈍足

# 最小構成ローグライク 要件概要

## 目的

現在の実装をベースに、初代「風来のシレン」風のダンジョン探索型ローグライクゲームとして遊べる状態を目指す。マスターデータの入れ替えで異なるローグライクゲームを擬似的に遊べるエンジンとする。

## 設計方針

- **データ駆動設計**: モンスター・アイテム・ダンジョン等の定義をコードから分離し、マスターデータ（RONファイル）で管理する
- **UI分離**: ゲームロジックとUI/レンダリングをtrait境界で分離し、将来の見下ろし2D UI（アスカ見参風）への移行に備える
- **段階的実装**: 汎用ローグライク骨格 → シレン風要素の順で進める

## 現状の実装済み機能

- BSPによるダンジョン自動生成（100x50）
- プレイヤー移動（vim風 hjklyubn + 方向キー）
- 複数階層（10階）の階段による進行
- モンスター生成（各階10体）とランダム移動AI
- 壁・モンスターとの衝突判定
- crossterm によるターミナル描画

## 実装の優先順位

```
[Phase 0] アーキテクチャ整備
  マップ表現変更 → モジュール分割 → Command/Event導入 → UI trait化 → マスターデータ外部化

[Phase 1] 汎用ローグライク骨格
  戦闘 → AI → UI → アイテム(基本) → 成長 → バランス
  ここまでで「動くローグライク」完成

[Phase 2] シレン風要素
  満腹度 → 装備 → 複数種モンスター → 食料 → 草・巻物 → 杖 → 投擲 → 視界
  ここまでで「シレン風ローグライク」として遊べる

[Phase 3] 発展要素
  ワナ → 未識別 → モンスターハウス → ダメージ式改善 → 持ち込み不可 → ...
```

## 基本ゲームループ

```
ダンジョン生成（フロア1）
  ↓
┌──────────────────────────────┐
│ プレイヤーの行動(GameCommand)  │
│  移動 / 攻撃 / アイテム / 待機 │
│         ↓                    │
│ モンスターの行動               │
│  追跡 / 攻撃 / 徘徊           │
│         ↓                    │
│ ターン終了処理                 │
│  満腹度減少 / 状態異常ターン経過 │
│         ↓                    │
│ 状態判定(GameEvent)           │
│  HP 0 → ゲームオーバー        │
│  階段到達 → 次の階へ          │
│  最終階クリア → 勝利          │
└────────┬─────────────────────┘
         ↓ (繰り返し)
```

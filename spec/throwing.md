# 投擲システム

## 概要

アイテムを直線方向に投げてモンスターに当てる遠距離攻撃手段。

## 基本仕様

- プレイヤーの向いている方向に直線で飛ぶ
- 壁に当たると消滅（アイテムは失われる）
- モンスターに当たるとダメージ + カテゴリ固有の効果
- 飛距離: 最大10マス（届かなければ地面に落ちる）

## 操作

- `t` キーで投擲モードに入る
- インベントリからアイテムを選択
- プレイヤーの向いている方向に投げる

## ダメージ計算

### 基本ダメージ

投擲アイテムのカテゴリに応じた固定ダメージ:

| カテゴリ | 投擲ダメージ |
|---------|------------|
| 草 | 2 + 効果適用 |
| 巻物 | 2 |
| 杖 | 2 |
| 食料 | 2 |
| 武器 | 武器の攻撃力 / 2 |
| 盾 | 2 |

### 草の投擲効果

草をモンスターに投げると、飲んだときと同じ効果がモンスターに適用される。

- 回復草を投げる → モンスターのHP25回復
- 毒草を投げる → モンスターの攻撃力低下
- 力の草を投げる → モンスターの攻撃力上昇

## キー操作

| キー | 操作 |
|------|------|
| t | 投擲モード（アイテム選択へ） |

## マスターデータ

投擲時の挙動はアイテムカテゴリの定義で管理する:

```ron
ItemCategoryDef(
    id: "herb",
    throwable: true,
    throw_damage: 2,
    throw_effect: ApplyToTarget,  // 効果を対象に適用
)
```

# 装備システム（武器・盾）

## 概要

武器と盾を装備してプレイヤーの攻撃力・防御力を強化する。強化値（+N）による成長要素を持つ。

## 装備スロット

| スロット | 効果 |
|---------|------|
| 武器 | 攻撃力に加算 |
| 盾 | 防御力に加算 |

- 各スロットに1つずつ装備可能
- 装備/解除はインベントリ画面から行う
- 装備中のアイテムもインベントリの枠を1つ使用する

## ステータス計算

```
実効攻撃力 = プレイヤー素の攻撃力 + 武器の攻撃力 + 武器の強化値
実効防御力 = プレイヤー素の防御力 + 盾の防御力 + 盾の強化値
```

## 強化値

- 武器・盾は強化値（+0〜+99）を持つ
- フロアで拾う武器・盾は +0〜+3 の範囲でランダム
- 強化手段は Phase 3 以降で追加（巻物等）

## データ構造

```rust
struct Equipment {
    id: String,
    name: String,
    symbol: char,
    category: EquipmentCategory,  // Weapon or Shield
    base_value: i32,              // 基礎攻撃力 or 基礎防御力
    enhancement: i32,             // 強化値
}

struct Player {
    // ...
    weapon: Option<usize>,   // インベントリ内のインデックス
    shield: Option<usize>,   // インベントリ内のインデックス
}
```

# 多様なアイテム（Phase 2）

## 概要

Phase 1 の薬草のみの構成から、草・巻物・杖・食料の4カテゴリに拡張する。

## アイテムカテゴリ

| カテゴリ | 記号 | 識別 | スタック | 投擲 |
|---------|------|------|---------|------|
| 草 | ! | 未識別あり | 不可 | 可（当たると効果適用） |
| 巻物 | ? | 未識別あり | 不可 | 可（ダメージのみ） |
| 杖 | / | 未識別あり | 不可 | 可（ダメージのみ） |
| 食料 | % | 常に識別済 | 不可 | 可（ダメージのみ） |

## 草（最小 5 種）

| 名前 | 効果 | 買値 |
|------|------|------|
| 薬草 | HP25回復。最大HP時に使うと最大HP+1 | 50 |
| 弟切草 | HP100回復 | 200 |
| 毒消し草 | 攻撃力低下を回復 | 100 |
| ちからの草 | 攻撃力+1（永続） | 500 |
| 毒草 | HP5減少、攻撃力-1（一時） | 50 |

### 草の投擲効果

草をモンスターに投げると、そのモンスターに効果が適用される。

## 巻物（最小 3 種）

| 名前 | 効果 |
|------|------|
| あかりの巻物 | フロア全体のマップが見える（モンスター・アイテム位置も表示） |
| 混乱の巻物 | フロア内の全モンスターが10ターン混乱する |
| パワーアップの巻物 | 攻撃力が15ターンの間 +5 される |

### 巻物の使用

- 読む（使う）と効果が発動し、消費される
- 投げても特殊効果は発動しない（ダメージのみ）

## 杖（最小 3 種）

| 名前 | 効果 | 初期回数 |
|------|------|---------|
| かなしばりの杖 | 対象を行動不能にする（ダメージを受けるまで） | 4-6 |
| ふきとばしの杖 | 対象を10マス後方に吹き飛ばす | 5-7 |
| 場所がえの杖 | 使用者と対象の位置を入れ替える | 3-5 |

### 杖の使用

- 振る（使う）と正面方向に魔法弾が直進し、最初に当たったモンスターに効果適用
- 壁に当たると消滅
- 回数が0になると効果が発動しない（「しかし何も起こらなかった」）
- 杖を投げても特殊効果は発動しない

## 未識別システム

### 基本仕様

- 草・巻物・杖はダンジョン入場時に未識別名がシャッフルされる
- 例: 「薬草」→「あおい草」、「弟切草」→「あかい草」...
- 使用すると正体が判明し、以降は正しい名前で表示される
- 同一ダンジョン内では識別状態が保持される

### 未識別名プール

各カテゴリごとに十分な数の未識別名をマスターデータで用意する。

```ron
// 草の未識別名プール
unidentified_names: [
    "あおい草", "あかい草", "きいろい草", "みどりの草",
    "むらさきの草", "しろい草", "くろい草", "にじいろの草",
]
```

## データ構造

```rust
enum ItemCategory {
    Herb,           // 草
    Scroll,         // 巻物
    Staff { charges: i32 },  // 杖（残り回数）
    Food,           // 食料
    Weapon,         // 武器（equipment.md）
    Shield,         // 盾（equipment.md）
}

struct Item {
    id: String,
    name: String,
    symbol: char,
    category: ItemCategory,
    identified: bool,       // 識別済みかどうか
}
```
